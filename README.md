# Fabric Generator 1.20.1 for MCreator 2026.2

**Status: Exploratory research.** This is not a finished product. It is an early-stage effort to keep a Fabric 1.20.1 generator alive on newer MCreator versions.

## What this is

A Fabric 1.20.1 generator plugin for MCreator, built on the lineage of [Goldorion's Fabric 1.20.1 Generator](https://github.com/Goldorion/Fabric-Generator-MCreator). Goldorion's generator is solid and stable to work with, but it has remained on older MCreator versions. This project continues that journey.

## Current goal

The priority is not adding features. It is compatibility:

- Keep the existing generator's functionality running on **MCreator 2026.2**.
- Update **Fabric API** and **Fabric Loader** to current versions.
- Only after that foundation is stable, consider selectively bringing in features from newer MCreator versions.

## Who this is for — and who it is not for

This is for people who still work with **Fabric 1.20.1** and want to stay on a newer MCreator workflow. It is **not** an official continuation of Goldorion's plugin, and it does not target newer Minecraft versions.
