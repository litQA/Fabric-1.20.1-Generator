# Fabric 1.20.1 Generator 

**Status: MCreator 2026.3 EAP baseline.** The generator is being migrated to MCreator 2026.3 EAP; feature parity work is in progress.

## What this is

A Fabric 1.20.1 generator plugin for MCreator, built on the lineage of [Goldorion's Fabric 1.20.1 Generator](https://github.com/Goldorion/Fabric-Generator-MCreator). Goldorion's generator is solid and stable to work with, but it has remained on older MCreator versions. This project continues that journey.

## Current goal

The current goal is to keep the generator usable on **MCreator 2026.3 EAP** and to restore the features that were previously missing:

- Keep the existing generator's functionality running on **MCreator 2026.3 EAP**.
- Embed the `datapack-1.20.1` and `forge-1.20.1` base layers so the plugin does not depend on MCreator's bundled 1.20.1 generators.
- Port the 2026.3 generator model (`base_types`, `types.base_*`) and then add the 2026.3 features and the previously missing triggers.

## Who this is for — and who it is not for

This is for people who still work with **Fabric 1.20.1** and want to stay on a newer MCreator workflow. It is **not** an official continuation of Goldorion's plugin, and it does not target newer Minecraft versions.

# MCreator - Minecraft Mod Maker

[![MCreator](https://mcreator.net/image/brand/mcreator300s.png)](https://mcreator.net/)

MCreator is an open-source software used to make Minecraft Java Edition mods, Minecraft Bedrock Edition Add-Ons, resource packs, and data packs using an intuitive easy-to-learn interface or with an integrated code editor. It is used worldwide by Minecraft players, aspiring mod developers, for education, online classes, and STEM workshops.
